# ✨ 项目亮点

🎬 精致动态墙界面：采用现代暗色主题（Dark Mode）与玻璃拟物化风格，提升视频浏览体验。

🌐 双语即时切换：内置全站 繁体中文 / 简体中文 无缝一键切换机制。

📱 全平台响应式支持：完美适应手机、平板与桌面电脑，随时随地开启快乐源泉。

🛡️ 无害警告拦截器：内置全局 ResizeObserver 防护机制，确保控制台干净零报错。

⚡ 轻量高效：无需复杂的后端构建，纯 HTML/JS/Tailwind CSS 即可迅速上线部署。

🛠️ 技术栈

前端框架/样式：HTML5, Tailwind CSS (CDN Version)

图标库：Font Awesome 6

组件嵌入：Elfsight Social Feed Widget

字体：Google Fonts (Noto Sans TC / SC)
